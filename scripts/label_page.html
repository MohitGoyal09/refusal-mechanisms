This page builds itself with JavaScript, so a static preview shows nothing. Open it in a real browser instead of an in-app preview pane:

cd ~/Code/safety-refusals
python3 -m http.server 8765 &
open http://localhost:8765/label.html

Serving over http rather than opening the file directly also avoids browsers that block local storage on file://, which is what remembers your progress.
